# m3u8文件下载器使用说明


其实主要是看每一个m3u8文件的格式是怎样的，这个代码只适合下载文件里面的那个m3u8文件
其他的要看结构是不是和他一样的。

但是万变不离其宗，只要你能看懂m3u8文件的格式，你就可以用这个代码下载其他的m3u8文件
m3u8文件的格式是这样的：
```text

#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXT-X-MEDIA-SEQUENCE:0
#EXTINF:9.009,
http://example.com/segment1.ts
#EXTINF:9.009,
http://example.com/segment2.ts
#EXTINF:[3.003,
http://example.com/segment3.]()ts
#EXT-X-ENDLIST

<!-- 
Explanation of common m3u8 tags:
#EXTM3U - File header indicating this is an m3u8 file
#EXT-X-VERSION - Version of the HLS protocol
#EXT-X-TARGETDURATION - Maximum duration of any segment
#EXT-X-MEDIA-SEQUENCE - Sequence number of first segment
#EXTINF - Duration of next segment followed by segment URL
#EXT-X-ENDLIST - Indicates no more segments will be added
-->   
```
前面是一些信息，后面是一些ts文件的地址
只要把ts的地址合并起来然后再下载就可以了

如果是加密的m3u8文件，那么就需要解密，解密的方法是在代码中添加解密的代码
m3u8文件解密的格式：
```text
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:2
#EXT-X-KEY:METHOD=AES-128,URI="https://app.xiaoe-tech.com/xe.basic-platform.material-center.distribute.zj.vod.get/1.0.0/kds/api/v1/keys?source=jarvis&ak=660562c00f6665322a5dcefe010d5dab",IV=0x00000000000000000000000000000000
#EXTINF:2,
main_0.ts?t=693da69c&us=mchLSxJuko&sign=65b93565164e5dc84cc6d21aa08bd535
```
这里面加密的方法是AES-128，解密的密钥是https://app.xiaoe-tech.com/xe.basic-platform.material-center.distribute.zj.vod.get/1.0.0/kds/api/v1/keys?source=jarvis&ak=660562c00f6665322a5dcefe010d5dab
iv是0000000000000000000000000000000，前面没有ox


我们用的话就看一下我们写的正则有没有提取到密钥和iv，如果没有的话，那么我们就需要自己添加解析的逻辑，只有正则的逻辑要改，其他的不用改
