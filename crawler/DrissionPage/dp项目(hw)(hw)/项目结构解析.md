# DrissionPage 项目结构解析

## 1. DSAnimePictures-main

### 项目概述
基于 Python 和 DrissionPage 库开发的 Anime-Pictures.net 图片爬虫，用于爬取海量高质量动漫图片。

### 功能特色
- 支持关键词、排除标签、排序方式、发布时间等多维度筛选
- 自定义每页图片数量，灵活控制爬取速度
- 断点续爬功能
- 自动保存图片至 `pictures` 文件夹
- 首次使用引导设置，参数自动保存

### 文件结构
```
DSAnimePictures-main/
├── README.md                  # 项目说明文档
└── WebCrawler(AnimePictures).py  # 爬虫主程序
```

### 文件说明
- **README.md**：项目介绍、功能特色、环境准备、使用说明和代码结构
- **WebCrawler(AnimePictures).py**：核心爬虫程序，包含 `picture` 类，实现登录、爬取和保存功能

## 6. SearchAllNewsPlatform-main

### 项目概述
一键搜索全网（微博、头条、搜狐）并下载图片、视频、文字的爬虫工具。

### 功能特色
- 支持多平台数据采集（微博、头条、搜狐等）
- 自动解析文本内容、图片、视频等媒体数据
- 灵活的数据过滤机制
- 支持数据本地存储，JSON格式
- 自动下载和保存媒体文件

### 文件结构
```
SearchAllNewsPlatform-main/
├── README.md            # 项目说明文档
├── all_search.py        # 统一搜索入口
├── filter.py            # 数据过滤模块
├── search_sohu.py       # 搜狐数据采集模块
├── search_toutiao.py    # 头条数据采集模块
├── search_weibo.py      # 微博数据采集模块
├── storage.py           # 数据存储模块
└── util.py              # 工具函数模块
```

### 文件说明
- **README.md**：项目介绍、功能特色、使用方法和数据格式
- **all_search.py**：统一搜索入口，整合各平台搜索功能
- **filter.py**：数据过滤模块，实现数据筛选功能
- **search_sohu.py**：搜狐平台数据采集模块
- **search_toutiao.py**：头条平台数据采集模块
- **search_weibo.py**：微博平台数据采集模块
- **storage.py**：数据存储模块，实现数据本地存储
- **util.py**：工具函数模块，提供通用功能支持

## 总结

本目录包含了多个基于 DrissionPage 开发的爬虫项目，涵盖了图片爬取、商品数据采集、社交媒体爬取、新闻爬取等多个领域。每个项目都有其特定的功能和用途，从简单的示例脚本到复杂的全站爬取系统，适合不同层次的爬虫开发者学习和参考。

这些项目展示了 DrissionPage 库的强大功能和灵活性，能够适应各种复杂的爬取场景，同时提供了丰富的数据分析和可视化功能，帮助开发者从爬取的数据中提取有价值的信息。
