## 文件同步脚本实现计划

**目标**：将 `C:\Users\35796\Documents\code\crawler\downloaded_videos` 中存在但 `F:\downloaded_videos` 中不存在的文件复制到F盘

**实现步骤**：

1. **获取两个文件夹的文件列表**
   - 使用 `os.listdir()` 或 `os.listdir()` 获取C盘文件夹的文件名列表
   - 使用 `os.listdir()` 获取F盘文件夹的文件名列表

2. **对比文件差异**
   - 将两个文件列表转换为集合
   - 使用集合差集运算找出C盘有但F盘没有的文件

3. **复制缺失的文件**
   - 遍历差异文件列表
   - 使用 `shutil.copy2()` 将文件从C盘复制到F盘
   - 添加进度提示，显示正在复制哪些文件

4. **错误处理**
   - 检查源文件夹和目标文件夹是否存在
   - 处理可能的文件复制错误（如权限问题、磁盘空间不足等）

**代码结构**：
- 导入必要的模块：`os`, `shutil`
- 定义源路径和目标路径
- 实现文件获取、对比和复制逻辑
- 添加友好的输出信息
